# Buzdolabı Işığı İstihbarat Servisi

> Resmi adı: BİİS. Gayriresmi adı: Yine mi açtın.

Bu depo, insanlığın en eski istihbarat açığını kapatır: buzdolabı kapısı aralandığı anda içeride ne arandığının devlet ciddiyetiyle belgelenmesi.

Işık yandıysa operasyon başlamıştır. Işık yanmadıysa ya ampul bitmiştir ya da sen karanlıkta peynir arayan bir efsanesin. Her iki durumda da servis suçlu değildir. Servis hiçbir zaman suçlu değildir. Servis ışıktır.

## Misyon

Kapı açılışını sınıflandırmak. Gerekçeyi sorgulamak. Turşu kavanozunu şüpheli paket ilan etmek. Çıktıyı aşırı resmi bir brifing haline getirmek. Sonra hiçbir şey değiştirmemek, çünkü asıl güç rapordadır, yoğurtta değil.

## Kurulum

Python 3 yeter. Bağımlılık yok. Dış istihbarat servisi yok. Sadece sen, kapı ve vicdanın.

```bash
python3 servis.py
```

Program sana neden açtığını sorar. Dürüst ol. Yalan söyle. Fark etmez. Işık zaten gördü.
